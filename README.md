# Acupuntura Clínica Especializada

Clínica especializada en acupuntura clínica y medicina tradicional china en la Ciudad de México. Situada en Benito Juárez, ofrecemos tratamientos integrativos con protocolos clínicos de vanguardia.

## Características

- **Diagnóstico Ryodoraku**: Tecnología avanzada para el diagnóstico energético.
- **Especialidades**: Dolor crónico, Fertilidad, Parálisis Facial, Ansiedad y Estrés.
- **Enfoque Integrativo**: Combinamos la medicina tradicional con rigor científico.
- **Diseño Responsivo**: Experiencia fluida en dispositivos móviles y de escritorio (Mobile-first).
- **Animaciones**: Transiciones suaves y micro-interacciones con Framer Motion.
- **WhatsApp Integrado**: Botón de contacto con funcionalidad de copiado de número para facilitar la comunicación y seguimiento de métricas.

## Tecnologías Utilizadas

- **Next.js 15**: Framework de React para el desarrollo web.
- **Tailwind CSS**: Diseño moderno y responsivo.
- **Framer Motion**: Animaciones fluidas.
- **Lucide React**: Iconografía minimalista.
- **TypeScript**: Seguridad de tipos para un código robusto.

## Instalación y Desarrollo

1. Clona el repositorio.
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Despliegue

El proyecto está listo para ser desplegado en plataformas como Vercel o Netlify.
